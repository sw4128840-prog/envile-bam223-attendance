# ENVILE POLYTECHNIC — BAM223 ATTENDANCE

This is a first working prototype of the student attendance app.

## Included
- Student name and ID login
- Monday-Friday attendance restriction
- One attendance record per student per day
- Automatic date and time recording
- Attendance history
- Local browser storage

## How to test
Open `index.html` in a web browser.

## Next production features
- Real student accounts
- Firebase database
- Admin/lecturer dashboard
- QR code verification
- GPS/school-location verification
- Real attendance reports
